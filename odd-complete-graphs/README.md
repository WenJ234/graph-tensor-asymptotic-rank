# Odd Complete Graph Tensors

For odd n ≥ 3, the base-two logarithm of the complex asymptotic rank of the binary graph tensor of K_n is n²/4, exactly 1/4 above its maximum cut. The manuscript treats all odd orders; K5 is the worked example, with exponent 25/4.

- [Author manuscript (PDF)](odd-complete-graph-tensors.pdf)
- [Finite verification script](verify_k5_reduction.py)

Run `python3 verify_k5_reduction.py` to check the finite K5 reduction and the grouping formulas. The script does not verify the external rectangular-exponent theorem. The [legacy k5 path](../k5/) remains available for existing links.
