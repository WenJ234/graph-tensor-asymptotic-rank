# Beyond the Maximum Cut for Graph Tensors

By Wen Jiang. The asymptotic rank exponent can strictly exceed the maximum cut even for triangle-free graphs. The paper gives a strict lower-bound gap for every odd cycle and determines the exponent for complete multipartite graphs.

- [Manuscript (PDF)](Beyond_the_Maximum_Cut_for_Graph_Tensors.pdf)
- [Finite verification script](verify_graph_certificates.py)
- [Original bundle](Graph_Tensors_Paper_and_Verification.zip)

Run `python3 verify_graph_certificates.py` for the finite cut and grouping checks. It does not verify the external theorems or the full paper. See the [separate five-cycle paper](../c5/) for the exact C5 upper bound.
