# Odd Complete Graph Tensors (Kn)

For odd n ≥ 3, the complex asymptotic rank exponent of the binary graph tensor of Kₙ is n²/4, exactly 1/4 above the maximum cut.

- [Author manuscript (PDF)](Kn-asymptotic-rank.pdf)
