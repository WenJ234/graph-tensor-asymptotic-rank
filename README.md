# Graph Tensor Asymptotic Rank

Research notes by Wen Jiang on graph tensors over the complex numbers.

- [Odd complete graph tensors](k5/): exact asymptotic rank exponent for odd complete graphs, with K5 as a worked example. Includes the signed manuscript and a finite verification script.
- [Five-cycle graph tensor](c5/): exact exponent 49/12. Includes the signed manuscript, full source archive, rational certificate, and two checkers.

Reproduction instructions and the scope of each verification are in the corresponding directory.
