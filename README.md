## The Exact Asymptotic Rank Exponents of Cycle Graph Tensors

**Wen Jiang, 2026 · Research manuscript**

[Read the signed paper (PDF)](cn/cycle-graph-tensors-Wen-Jiang.pdf) · [Source and exact rational certificates (ZIP)](cn/cycle-proof-sources-and-certificates.zip) · [Reproduction instructions](cn/)

The manuscript determines the base-two logarithm of the asymptotic rank of the binary cycle graph tensor over the complex numbers. For an even cycle of length n it is n; for an odd cycle it is n − 1 + 1/[4(n − 2)]. The companion archive includes exact checks for small odd cycles and a uniform certificate for all larger odd cycles. These checks are not an end-to-end Lean 4 proof.

Keywords: graph tensors, asymptotic rank, tensor rank, odd cycles, rectangular matrix multiplication, algebraic complexity.
