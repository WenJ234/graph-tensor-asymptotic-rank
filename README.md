# Graph Tensor Asymptotic Rank


Research notes by Wen Jiang on graph tensors over the complex numbers.


- [Odd complete graph tensors (Kn)](Kn/): exact asymptotic rank exponent for odd complete graphs. Includes the signed manuscript and a finite verification script.
- [Five-cycle graph tensor](c5/): exact exponent 49/12. Includes the signed manuscript, full source archive, rational certificate, and two checkers.
- [Cycle graph tensors (Cn)](cn/): the original signed manuscript on exact exponents for all cycle lengths.
- [Wheel graph tensors](wheel/): exact asymptotic rank exponents for wheel graphs; includes the signed manuscript.

Reproduction instructions and the scope of each verification are in the corresponding directory.
