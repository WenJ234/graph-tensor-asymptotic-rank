# Odd complete graph tensors

Research note by Wen Jiang. The paper derives the exact asymptotic rank exponent for odd complete graphs, including 25/4 for K5, from cited results.

- [Manuscript PDF](k5-asymptotic-rank%281%29.pdf)
- [Reproduction script](verify_k5_reduction.py): run `python3 verify_k5_reduction.py`. It checks the finite reduction and algebra, not the external Lean theorem.
